PRÓXIMOS PASOS (IMPORTANTE)
================================================================================

1️⃣  CREAR NUEVA CUENTA RAILWAY
   URL: https://railway.app/
   Nota: Usa una nueva dirección de email si tu saldo se agotó

2️⃣  CREAR NUEVO PROYECTO EN RAILWAY
   • Haz clic en "New Project"
   • Selecciona "Create a new service"
   • Elige "Database" → "PostgreSQL" para la BD
   • Railway te dará credenciales automáticamente

3️⃣  VINCULAR TU REPOSITORIO
   Opción A (Recomendado - desde GitHub):
   • En Railway, selecciona "Deploy from GitHub"
   • Conecta tu cuenta de GitHub
   • Selecciona este repositorio

   Opción B (Desde línea de comandos):
   • Ejecuta: .\deploy_to_new_railway.ps1
   • Sigue las instrucciones interactivas

4️⃣  CONFIGURAR VARIABLES DE ENTORNO
   En el dashboard de Railway, ve a "Settings" → "Variables"
   Necesitas copiar estas líneas (Railway las proporcionará):

   POSTGRES_URL_NON_POOLING=postgresql://...

   Y configura estas:
   DJANGO_SETTINGS_MODULE=production_control.settings
   DEBUG=False
   ALLOWED_HOSTS=tu-dominio-railway.app
   SECURE_SSL_REDIRECT=1

5️⃣  EJECUTAR MIGRACIONES
   Una vez que el servidor esté corriendo:
   railway run python manage.py migrate --settings=production_control.settings

6️⃣  VERIFICAR QUE TODO FUNCIONA
   • Abre tu dominio de Railway en el navegador
   • Comprueba que la BD está conectada
   • Verifica los logs: railway logs

SEGURIDAD Y MEJORES PRÁCTICAS
================================================================================

✅ HACER:
