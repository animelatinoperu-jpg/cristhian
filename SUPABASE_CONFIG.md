# 🚀 Configuración de Supabase para Django

Supabase está creando tu BD PostgreSQL gratuita en este momento.

✅ BD PostgreSQL (500 MB gratis)

### Próximos pasos:
1. **Esperar a que Supabase termine** (~2 minutos)
2. **Copiar credenciales de conexión**
3. **Actualizar `.env` de Django**
4. **Migrar datos**
5. **Deploy a Railway con Supabase**

### Variables de entorno que necesitarás:
```
POSTGRES_HOST=tu-proyecto.supabase.co
POSTGRES_PORT=5432
POSTGRES_DB=postgres
POSTGRES_USER=postgres
POSTGRES_PASSWORD=[será proporcionada]
```
